# تست‌های خودکار

| دستور | چه چیزی را می‌آزماید |
|---|---|
| `npm test` | تست‌های واحد + تست موتورهای واقعی برنامه (فروش، انبار، فاکتور، همگام‌سازی آفلاین با سرور شبیه‌سازی‌شده، پشتیبان‌گیری، احراز هویت، فایل‌ها، تراکنش) |
| `npm run test:e2e` | سناریوی کامل PWA در مرورگر واقعی: نصب/کش ← قطع اینترنت ← بستن کامل ← بازکردن آفلاین ← فروش و دریافت وجه ← بستن ← وصل اینترنت ← همگام‌سازی بدون رکورد تکراری |

برای e2e: `playwright-core` و یک Chromium لازم است (`PW_CHROMIUM=/مسیر/chrome`).
