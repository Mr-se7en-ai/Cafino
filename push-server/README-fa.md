# سرویس اعلان کافینو (Web Push)

وقتی برنامه بسته است، مرورگر/موبایل فقط از طریق یک سرور می‌تواند اعلان بگیرد. این سرویس کوچک (Node 18+) اشتراک مرورگرها و زمان‌بندی یادآورها را نگه می‌دارد و سر وقت پیام را می‌فرستد.

## راه‌اندازی
```
cd push-server
npm install
npm start          # کلیدهای VAPID را می‌سازد (data/vapid.json) و کلید عمومی را چاپ می‌کند
```
متغیرهای محیطی (اختیاری): `PORT` (۸۷۸۷)، `DATA_DIR`، `VAPID_SUBJECT` (مثل `mailto:you@example.com`)، `ALLOWED_ORIGINS` (نشانی سایت کافینو؛ خالی = همه)، `PUSH_SHARED_KEY`، `TICK_SECONDS` (۲۰).

سرویس باید پشت **HTTPS** باشد (مثلاً با Nginx/Caddy)، چون مرورگرها Web Push را فقط روی HTTPS می‌پذیرند.

## اتصال برنامه
در `config.js` کنار برنامه:
```
window.CAFINO_CONFIG = { apiBaseUrl: "", cafeId: "", pushUrl: "https://push.example.com", vapidPublicKey: "<کلید عمومی>", pushKey: "" };
```
بعد در برنامه: «یادداشت و یادآوری ← فعال‌کردن اعلان پس‌زمینه».

## نکته‌ها
- برنامه باید روی HTTPS و به‌صورت PWA/سایت باز شود (با `file://` کار نمی‌کند). روی آیفون ابتدا «افزودن به صفحهٔ اصلی».
- در ایران، اعلان‌های Chrome/Android از سرویس FCM گوگل رد می‌شوند؛ اگر سرور شما یا کاربر به آن دسترسی نداشته باشد اعلان نمی‌رسد. قبل از استفادهٔ واقعی با «اعلان آزمایشی» امتحان کنید.
- سرویس فقط عنوان/توضیح یادآور و زمان‌ها را نگه می‌دارد (در `data/push-store.json`)؛ یادآورهای انجام‌شده یا حذف‌شده با همگام‌سازی بعدی برنامه از سرویس برداشته می‌شوند.
- نوبت‌های یادآور تکرارشونده برای ۱۲۰ روز آینده فرستاده و هر بار که برنامه باز شود تازه می‌شود.
