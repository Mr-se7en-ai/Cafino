# ساختار کد برنامه (src/app)

`App.jsx` فقط پوستهٔ برنامه است (ورود، تم، فونت). بقیه منطق در این پوشه‌هاست:

| پوشه | محتوا |
|---|---|
| `core/` | ثابت‌ها، تاریخ شمسی، قالب‌بندی، تم، لاگ فعالیت، نسخه و تغییرات، منوها |
| `domain/` | منطق کسب‌وکار بدون صفحه: موتور فروش (`sales`), ابطال‌ها، باشگاه مشتریان، پشتیبان‌گیری، دستور مصرف، شارژ/اینترنت، تعهدات |
| `components/` | اجزای مشترک: نمودارها، انتخاب‌گر، تقویم، خروجی گزارش، باشگاه |
| `pages/` | هر صفحه (مشتریان، سفارش‌ها، دفتر حساب، فاکتورها، انبار، صندوق، گزارش‌ها، داشبورد، تعرفه، تنظیمات …) |
| `app/` | `MainApp` (چارچوب اصلی پس از ورود) و `AuthScreen` |

بیرون از این پوشه: `src/data` (ذخیره‌سازی، تراکنش، فایل‌های رمزنگاری‌شده)، `src/sync` (صف آفلاین)، `src/diagnostics` (خطایابی)، `src/services` (API و احراز هویت)، `src/voice` (دستیار صوتی).

نکتهٔ شناخته‌شده: چند ماژول هنوز به هم وابستگی دوطرفه دارند (مثلاً موتور فروش به کلیدهای ذخیره‌سازی صفحه‌ها و `nextInvNum`). بارگذاری برنامه ایمن است (هیچ وابستگی چرخه‌ای در زمان بارگذاری نیست)، اما گام بعدی تمیزکاری، انتقال این موارد به `core/constants` و `domain` است تا جهت وابستگی همیشه core ← domain ← pages باشد.
